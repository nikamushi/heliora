# HELIORA Mobile Production Release — Integrasi Ekosistem Web & Backend Cerdas

Selamat datang di rilis produksi resmi aplikasi mobile HELIORA untuk platform Android. Versi ini menghadirkan pengalaman prevensi kesehatan kardiometabolik terpadu yang terhubung langsung dan tersinkronisasi penuh dengan ekosistem web `https://heliora.software` serta backend AI real-time `https://api.heliora.software`.

### Sorotan Fitur & Integrasi:
- **Sinkronisasi Ekosistem Web Terpadu**: Akses satu akun terpadu berbasis Supabase Auth. Riwayat asesmen dan profil kesehatan Anda di mobile langsung terhubung dengan dashboard analitik web.
- **Konektivitas API & AI Prevensi Real-time**: Terhubung langsung ke high-performance backend `https://api.heliora.software` untuk inferensi estimasi risiko kardiometabolik 10-tahun dan simulasi gaya hidup interaktif (*What-if Simulator*).
- **Keamanan Data & Privasi Terstandar (UU PDP No. 27/2022)**: Persetujuan pemrosesan data medis 2-langkah dengan penyimpanan kredensial token terenkripsi pada hardware keystore perangkat (`flutter_secure_storage`).
- **Explainable AI (XAI) Terarah**: Visualisasi faktor kontributor risiko berbasis SHAP yang transparan dan rekomendasi klinis terarah dari tim medis.
- **Dukungan Resmi Terverifikasi**: Dukungan pengguna langsung via email resmi `autoruns18@gmail.com` dan tata kelola di bawah naungan **Team Parental Advisory Explicit Content**.

### Berkas Instalasi:
- Unduh file APK di bawah dan pasang pada perangkat fisik Android (Android 8.0+ / API 26 ke atas).
